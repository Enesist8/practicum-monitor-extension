PRACTICUM MONITOR — РАСШИРЕНИЕ 0.3.0

УСТАНОВКА

1. Скачайте ZIP-архив расширения.
2. Распакуйте архив в отдельную папку.
3. Откройте страницу расширений:
   Яндекс Браузер: browser://extensions/
   Google Chrome: chrome://extensions/
4. Включите «Режим разработчика».
5. Нажмите «Загрузить распакованное расширение».
6. Выберите распакованную папку, в которой находится manifest.json.

ПОДКЛЮЧЕНИЕ СТУДЕНТА

1. Администратор создаёт индивидуальный одноразовый код подключения для студента.
2. Студент открывает Practicum Monitor в браузере и вводит полученный код в окне расширения.
3. После успешного подключения расширение начинает передавать данные.
4. Студент должен быть авторизован в Яндекс Практикуме в этом же браузере.

ВАЖНО

- У каждого студента должен быть собственный код подключения.
- Не передавайте свой код другим студентам.
- Не удаляйте расширение после подключения.
- Для передачи данных используется защищённое соединение HTTPS.
